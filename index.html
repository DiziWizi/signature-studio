Import an existing signature

Paste the HTML of a signature you already use. Signature Studio will try to recover the name, contact details, links and images. It’s best-effort — always review the result.

Install in your mail client

  1. Choose Export ▸ Copy to clipboard above.
  2. Gmail → ⚙ Settings → See all settings → General → Signature.
  3. Create a new signature, click in the edit box and paste (Ctrl/Cmd+V).
  4. Under Signature defaults, select it for new emails and replies. Save changes.

Gmail simplifies some formatting. If images vanish, use a hosted image URL (not an uploaded one) and paste again.

  1. Choose Export ▸ Copy to clipboard.
  2. File → Options → Mail → Signatures… → New.
  3. Click in the signature editor and paste with right-click → Keep Source Formatting (or Ctrl+V).
  4. Set the defaults for New messages and Replies/forwards, then OK.

Outlook renders signatures with the Word engine — these templates are built for it, but tiny differences are normal. Test once by sending yourself an email.

  1. Choose Export ▸ Copy to clipboard.
  2. Outlook → Settings (⌘+,) → Signatures.
  3. Click +, paste (⌘V), then set the signature for your account.
  1. Choose Export ▸ Copy to clipboard.
  2. Mail → Settings (⌘+,) → Signatures → select your account → +.
  3. Paste (⌘V) and close. The signature syncs to iPhone/iPad if your account uses iCloud sync.
  1. Choose Export ▸ Copy to clipboard.
  2. Account Settings → select the account → Signature text.
  3. Tick Use HTML, paste (Ctrl/Cmd+V) and close the dialog.
  1. Choose Export ▸ Copy to clipboard.
  2. Proton: Settings → Identity and addresses → Signature → paste.
  3. Outlook on the web: Settings → Mail → Compose and reply → signature → paste.
  4. Fastmail: Settings → Accounts → your account → Signature → paste.
  5. Any other client with a rich-text signature box: paste with formatting intact.

Not every client keeps every style. Keep signatures ≤ 600 px wide, use hosted images, and test in the client your recipients actually use.
